# Global Superstore Sales Analysis
Global Superstore Sales Data Analysis using Python, Pandas, Matplotlib &amp; Seaborn.

## Project Overview

This project analyzes the Global Superstore dataset to identify sales and profit trends and generate useful business insights.

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Analysis Performed

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Year-wise Sales and Profit analysis
* Regional performance analysis
* Category-wise Sales and Profit analysis
* Identification of trends and business insights
* Data visualization using charts

## Key Insights

* Sales and profit were analyzed across different years to identify growth trends.
* Regional performance was compared to identify strong and weak-performing regions.
* Category-level analysis was performed to understand which product categories contribute most to sales and profit.
* Visualizations were used to make the business trends easier to understand.

## Files

* `Global_Superstore_Analysis.ipynb` — Complete Python data analysis and visualizations.
* `Global_Superstore.csv` — Dataset used for the analysis.

## Objective

The main objective of this project is to demonstrate practical data analysis skills using Python and extract meaningful business insights from real-world sales data.
